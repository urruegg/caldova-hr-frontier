## Purpose and Authority

This folder retains obsolete documentation that still has historical or audit value. Archived records are not current implementation authority; their maintained catalogue identifies current replacements.

## Contains and Does Not Contain

This folder contains immutable or maintained historical sets with an owning catalogue. It does not contain active specifications, plans, operational runbooks, generated evidence, or redirect stubs.

## Reading Order

Start at the [documentation knowledge map](../README.md), select the historical set below, then use that set's catalogue. Do not link directly to an immutable snapshot for current guidance.

## Naming and Lifecycle

Move content here only when it is no longer authoritative and historical value justifies retention. Preserve immutable snapshots byte-for-byte. Add or maintain a catalogue that records original purpose and current replacement; supersession updates both the active owning README and the archive catalogue in the same pull request.
