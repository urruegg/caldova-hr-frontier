Each journey keeps one colour on every surface: icon background, Copilot Studio icon colour and accent colour, Teams `accentColor`, agent cards and catalog headers. Agents are told apart by their glyph, not by shades.

Contrast follows Microsoft's icon guidance (4.5:1 recommended for best accessibility). D3 uses GF's interface orange (`#BC5A26`, 4.54:1) because the theme orange `#DB6B30` reaches only 3.4:1 with a white glyph. D5 uses a petrol glyph on pale green.

## 4. Usage rules

- **Icons:** full-bleed journey colour, glyph in the journey's glyph colour, nothing else (see `docs/icons-and-visuals.md`).
- **Copilot Studio:** upload the colour icon; under *Colors* set the journey colour as icon colour or accent colour.
- **Teams / Microsoft 365 app details:** `accentColor` = journey colour (in each agent's `identity.json`).
- **Cards, pages, Adaptive Cards:** body text `#282828`, backgrounds white or GF grey `#F8F8F8`, journey tint for chips and headers; use Arial - Rockwell is often missing on client devices.
- **Never** introduce new colours for single agents; never lighten D3 or the DEV band (they sit just above 4.5:1).

## 5. Changes compared with the blueprint mockup v0.4

D1, D2 and D3 keep their colours. D4 moves from the website petrol `#0A3D50` to the theme petrol `#003E51` (almost identical). D5 moves from slate `#5B6770`, which is not a GF colour, to GF pale green `#ADDC91`. D6 moves from `#1576A8` to GF graphite `#323232` for the internal builder agents. We recommend aligning the next mockup version with this palette.
